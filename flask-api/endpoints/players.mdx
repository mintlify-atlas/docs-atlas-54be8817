## Overview

The Player endpoints provide access to Premier League player statistics, including goals scored and assists provided. Data can be retrieved in JSON format or exported as CSV/JSON files.

## Get Top Goalscorers

<CodeGroup>
```bash GET /players/goals
curl "http://localhost:5000/players/goals?season=2023-2024&limit=10&league=Premier%20League"
```
</CodeGroup>

Retrieve a list of top goalscorers with detailed statistics.

### Query Parameters

<ParamField query="season" type="string" optional>
  Filter results by season. Format: `YYYY-YYYY` (e.g., `2023-2024`)
  
  Defaults to current season if not specified.
</ParamField>

<ParamField query="limit" type="integer" optional>
  Maximum number of results to return.
  
  Must be a positive integer. If not specified, returns all available results.
</ParamField>

<ParamField query="league" type="string" optional default="Premier League">
  Filter results by league name.
  
  Supported values: `Premier League`, `La Liga`, `Serie A`, `Ligue 1`, `Bundesliga`
</ParamField>

### Response

<ResponseField name="response" type="array">
  Array of player objects with goal scoring statistics
  
  <Expandable title="Player Object">
    <ResponseField name="Name" type="string">
      Player's full name
    </ResponseField>
    
    <ResponseField name="Country" type="string">
      Player's nationality
    </ResponseField>
    
    <ResponseField name="Club" type="string">
      Current club name
    </ResponseField>
    
    <ResponseField name="Goals" type="string">
      Total goals scored
    </ResponseField>
    
    <ResponseField name="In Play Goals+Penalty" type="string">
      Breakdown of goals (open play + penalties)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseExample>
```json 200 Success
[
  {
    "Name": "Erling Haaland",
    "Country": "Norway",
    "Club": "Manchester City",
    "Goals": "27",
    "In Play Goals+Penalty": "21+6"
  },
  {
    "Name": "Cole Palmer",
    "Country": "England",
    "Club": "Chelsea",
    "Goals": "22",
    "In Play Goals+Penalty": "13+9"
  },
  {
    "Name": "Alexander Isak",
    "Country": "Sweden",
    "Club": "Newcastle United",
    "Goals": "21",
    "In Play Goals+Penalty": "19+2"
  }
]
```

```json 400 Invalid Limit
{
  "error": "Limit must be a number"
}
```

```json 400 Invalid Season
{
  "error": "Season format must be YYYY-YYYY"
}
```
</ResponseExample>

## Export Goalscorers to CSV

<CodeGroup>
```bash GET /players/goals/csv_file
curl "http://localhost:5000/players/goals/csv_file?filename=top_scorers&season=2023-2024&limit=20&header=Top%20Scorers" \
  -o top_scorers.csv
```
</CodeGroup>

Export top goalscorers data to a CSV file.

### Query Parameters

<ParamField query="filename" type="string" required>
  Name for the exported file (without extension).
  
  The filename will be sanitized for security. Special characters and path separators will be removed.
</ParamField>

<ParamField query="season" type="string" optional>
  Filter results by season. Format: `YYYY-YYYY` (e.g., `2023-2024`)
</ParamField>

<ParamField query="limit" type="integer" optional>
  Maximum number of results to include in the export.
</ParamField>

<ParamField query="header" type="string" optional>
  Include a header row in the CSV file with this text.
</ParamField>

<ParamField query="league" type="string" optional default="Premier League">
  Filter results by league name.
</ParamField>

### Response

<ResponseField name="file" type="file">
  CSV file download with `text/csv` MIME type.
  
  The file contains player statistics with columns: Name, Country, Club, Goals, In Play Goals+Penalty
</ResponseField>

### Error Responses

<ResponseExample>
```json 400 Missing Filename
{
  "error": "Missing filename parameter"
}
```

```json 400 Invalid Limit
{
  "error": "Limit must be a number"
}
```
</ResponseExample>
